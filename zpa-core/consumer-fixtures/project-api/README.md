# Project API consumer fixture (`:project-api-consumer-test`)

Independent Java and Kotlin consumers of the supported `com.felipebz.zpa.api.project` API, using a realistic
multi-file package specification/body fixture. It is a normal, **non-published** subproject of the ZPA build
(registered in the root `settings.gradle.kts`), with its own source set and no publishing, license or JReleaser
conventions.
