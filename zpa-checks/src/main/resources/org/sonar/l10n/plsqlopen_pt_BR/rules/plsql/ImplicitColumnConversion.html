Quando o Oracle compara um valor de caracteres com um número, ele converte o valor de caracteres para número; quando o compara com uma data, ele o converte para data. Se o lado de caracteres é uma coluna, o Oracle converte o valor de cada linha. Um índice normal nessa coluna deixa de ser usado para a condição, e uma linha cujo valor não é um número ou uma data válida lança um erro (ORA-01722 para número), mesmo uma linha que a consulta não retornaria. O código compila, e só falha ou fica lento com certos dados.

Esta regra reporta uma comparação em uma condição SQL (=, <>, <, >, IN com lista, BETWEEN) entre uma coluna VARCHAR2, CHAR, NVARCHAR2 ou NCHAR e um número ou uma data: um literal, uma variável ou um parâmetro PL/SQL, ou uma coluna de outra origem. Ela usa os tipos das colunas lidos do banco, ou os das tabelas criadas nos fontes do projeto, e não reporta nada sem eles.

Exemplo de código não conforme

-- rack.label é VARCHAR2
select count(*)
  into found
  from rack
 where label = 42;

Solução conforme

select count(*)
  into found
  from rack
 where label = '42';

select count(*)
  into found
  from rack
 where label = to_char(p_number);
