Um cursor declarado e nunca usado é código morto. A sua consulta continua sendo lida, revisada e mantida em sincronia com as tabelas por quem mantém o código, sem nenhum proveito.

Esta regra reporta um cursor local, ou de um package body, que nenhum código do arquivo usa: não é aberto, lido com fetch, fechado nem percorrido por um laço FOR de cursor, e não é nomeado por um atributo (%ISOPEN, %ROWTYPE...). Cursores de uma especificação de pacote não são reportados, nem um cursor de package body declarado com RETURN, que pode implementar um cursor da especificação. Como nas variáveis, um cursor só é reportado quando a análise prova que ele não é usado.

Exemplo de código não conforme

declare
  cursor c_racks is select id from rack where active = 'Y';
  cursor c_bins is select id from bin; -- Noncompliant
begin
  for r in c_racks loop
    refresh_rack(r.id);
  end loop;
end;

Solução conforme

declare
  cursor c_racks is select id from rack where active = 'Y';
begin
  for r in c_racks loop
    refresh_rack(r.id);
  end loop;
end;
