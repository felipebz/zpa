Num comando SQL, o Oracle incrementa uma sequence uma vez para cada linha que referencia o seu NEXTVAL, qualquer que seja o ramo do CASE ou do DECODE que a linha segue. Um NEXTVAL escrito num resultado condicional é, portanto, consumido para toda linha, também para as que recebem o outro resultado: a sequence avança mais rápido do que o esperado e deixa lacunas.

Esta regra reporta NEXTVAL num resultado de uma expressão CASE, ou do DECODE nativo, num comando SQL de código PL/SQL, quando o nome é uma sequence que o projeto cria. Sequences fora do projeto analisado não são reconhecidas. Em vez disso, filtre na cláusula WHERE as linhas que precisam de um valor.

Exemplo de código não conforme

create procedure label_new_crates is
begin
  insert into crate_label (crate_id, label_no)
  select c.id, case when c.status = 'NEW' then label_seq.nextval end -- Noncompliant
    from crate c;
end;

Solução conforme

create procedure label_new_crates is
begin
  insert into crate_label (crate_id, label_no)
  select c.id, label_seq.nextval
    from crate c
   where c.status = 'NEW';
end;
