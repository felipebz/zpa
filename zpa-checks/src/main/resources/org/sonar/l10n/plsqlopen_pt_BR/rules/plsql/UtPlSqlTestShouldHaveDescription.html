O utPLSQL aceita um teste sem descrição e mostra o nome da procedure no seu relatório. Uma descrição diz em palavras simples o que o teste verifica, e o relatório e quem o lê dependem disso.

Esta regra reporta um %test sem descrição. Um %displayname(descrição) no teste também conta, mas %test(descrição) é preferível: o utPLSQL documenta o %displayname como redundante.

Exemplo de código não conforme

create package crate_test as
  --%suite
  --%test -- Noncompliant
  procedure creates_crate;
end;

Solução conforme

create package crate_test as
  --%suite
  --%test(Creates a crate with the next free code)
  procedure creates_crate;
end;
