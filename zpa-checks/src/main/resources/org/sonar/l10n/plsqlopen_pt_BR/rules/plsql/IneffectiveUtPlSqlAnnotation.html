O utPLSQL lê anotações só das especificações de pacote. Uma anotação escrita num package body é um comentário que o compilador aceita e o utPLSQL nunca vê: a procedure não é executada como teste, ou a configuração não é aplicada.

Esta regra reporta uma anotação do utPLSQL escrita num package body. Mova-a para a declaração da procedure na especificação.

Exemplo de código não conforme

create package body crate_test as
  --%test(Creates a crate) -- Noncompliant
  procedure creates_crate is
  begin
    ut.expect(crate_count).to_equal(1);
  end;
end;

Solução conforme

create package crate_test as
  --%suite
  --%test(Creates a crate)
  procedure creates_crate;
end;
