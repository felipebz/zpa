cursor%NOTFOUND é a negação de cursor%FOUND, inclusive para nulo: os dois são nulos antes do primeiro fetch, e os dois lançam INVALID_CURSOR num cursor explícito que não está aberto. Escrever NOT cursor%FOUND acrescenta um operador que o leitor precisa desfazer para entender a condição.

Esta regra reporta NOT cursor%FOUND, em cursores explícitos e no cursor implícito (NOT SQL%FOUND).

Exemplo de código não conforme

loop
  fetch c_crates into r_crate;
  exit when not c_crates%found; -- Noncompliant
  process_crate(r_crate);
end loop;

Solução conforme

loop
  fetch c_crates into r_crate;
  exit when c_crates%notfound;
  process_crate(r_crate);
end loop;
