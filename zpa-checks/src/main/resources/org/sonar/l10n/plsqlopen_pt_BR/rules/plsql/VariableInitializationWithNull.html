Uma variável ou campo de record declarado sem valor padrão começa nulo. Inicializá-lo com NULL, ou com '', que o Oracle trata como nulo, repete o padrão e faz o leitor procurar um motivo que não existe.

Esta regra reporta uma variável ou campo de record inicializado com NULL ou '', por := ou DEFAULT. O valor padrão de um parâmetro não é reportado: ali, DEFAULT NULL torna o parâmetro opcional.

Exemplo de código não conforme

declare
  l_label varchar2(30) := null; -- Noncompliant
  type t_slot is record (code varchar2(10) default ''); -- Noncompliant
begin
  l_label := slot_label(42);
end;

Solução conforme

declare
  l_label varchar2(30);
  type t_slot is record (code varchar2(10));
begin
  l_label := slot_label(42);
end;
