O DBMS_OUTPUT escreve num buffer da sessão que só um cliente que o habilita lê, como o SQL*Plus com SET SERVEROUTPUT ON. Chamado por uma aplicação, um job ou um trigger, o texto é descartado, ou fica no buffer até a sessão terminar: o que o código queria informar se perde. Diagnósticos pertencem ao log da aplicação, e mensagens para o usuário, aos valores que o código retorna ou aos erros que ele lança.

Esta regra reporta chamadas a DBMS_OUTPUT.PUT e DBMS_OUTPUT.PUT_LINE, com ou sem o schema SYS, no código principal. Código de teste não é verificado.

Exemplo de código não conforme

create procedure purge_bins(p_days number) is
begin
  delete from bin_history where moved_at < sysdate - p_days;
  dbms_output.put_line(sql%rowcount || ' rows purged'); -- Noncompliant
end;

Solução conforme

create procedure purge_bins(p_days number) is
begin
  delete from bin_history where moved_at < sysdate - p_days;
  log_pkg.info('purge_bins', sql%rowcount || ' rows purged');
end;
