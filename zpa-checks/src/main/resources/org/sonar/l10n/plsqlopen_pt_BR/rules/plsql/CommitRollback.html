Uma transação pertence a quem a inicia: a aplicação, o job ou o cliente que chama o subprograma. Um COMMIT ou ROLLBACK dentro de um subprograma armazenado ou trigger encerra também a transação de quem chamou, que não pode mais desfazer o próprio trabalho, ou o perde, e o subprograma não pode ser reutilizado dentro de uma transação maior.

Esta regra reporta COMMIT e ROLLBACK em código armazenado. Não reporta ROLLBACK TO SAVEPOINT, que desfaz só o trabalho do próprio subprograma, código em blocos anônimos e scripts, nem código num subprograma ou trigger declarado com PRAGMA AUTONOMOUS_TRANSACTION, cuja transação é só dele.

Exemplo de código não conforme

create procedure move_crate(p_crate in number, p_rack in number) is
begin
  update crate set rack_id = p_rack where id = p_crate;
  commit; -- Noncompliant
end;

Solução conforme

create procedure move_crate(p_crate in number, p_rack in number) is
begin
  update crate set rack_id = p_rack where id = p_crate;
end;
