O utPLSQL executa as procedures nomeadas em anotações de preparação e limpeza (%beforeall(proc), %aftereach(proc)...) como chamadas de procedure de pacote sem argumentos. Quando o nome não leva a uma procedure assim, a preparação ou a limpeza não é executada, embora o pacote compile.

Esta regra reporta uma referência de preparação ou limpeza que não leva a nenhuma procedure pública das especificações de pacote analisadas, ou leva a uma que não pode ser chamada sem argumentos, ou a mais de uma. Um pacote que não está no projeto analisado pode existir no banco: uma referência a ele não é reportada.

Exemplo de código não conforme

create package crate_test as
  --%suite
  --%beforeall(load_crates) -- Noncompliant

  --%test(Creates a crate)
  procedure creates_crate;
end;

Solução conforme

create package crate_test as
  --%suite
  --%beforeall(load_crates)

  --%test(Creates a crate)
  procedure creates_crate;
  procedure load_crates;
end;
