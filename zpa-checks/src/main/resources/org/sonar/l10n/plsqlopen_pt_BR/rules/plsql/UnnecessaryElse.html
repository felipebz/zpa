Quando a cláusula IF de uma estrutura IF-THEN-ELSE não completa normalmente, a cláusa ELSE é desnecessária.

Exemplo de código não conforme

BEGIN
  IF condition THEN
    RETURN value;
  ELSE
    value := NULL;
  END IF;
END;

Solução conforme

BEGIN
  IF condition THEN
    RETURN value;
  END IF;
  
  value := NULL;
END;
