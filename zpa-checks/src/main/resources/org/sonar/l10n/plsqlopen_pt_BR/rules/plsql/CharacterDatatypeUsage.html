O VARCHAR hoje é sinônimo de VARCHAR2, mas o Oracle o reserva para um tipo futuro com outra semântica de comparação: código declarado com ele pode mudar de comportamento. O CHAR completa todo valor com espaços até o seu tamanho, então um valor lido num VARCHAR2 ou comparado com um carrega os espaços, e comparações e buscas se comportam de forma inesperada.

Esta regra reporta uma declaração do tipo CHAR ou VARCHAR. Use VARCHAR2.

Exemplo de código não conforme

declare
  l_code char(10); -- Noncompliant
  l_label varchar(30); -- Noncompliant
begin
  select code, label into l_code, l_label from crate where id = 42;
end;

Solução conforme

declare
  l_code varchar2(10);
  l_label varchar2(30);
begin
  select code, label into l_code, l_label from crate where id = 42;
end;
