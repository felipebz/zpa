Um parâmetro concatenado ao texto de um comando SQL dinâmico (EXECUTE IMMEDIATE, OPEN … FOR, DBMS_SQL.PARSE) permite que quem chama o subprograma escreva parte do comando. Um valor com aspas o altera: x' or '1'='1 transforma a busca de uma linha na busca de todas as linhas (SQL injection).

Passe um valor como variável de ligação com USING: o Oracle nunca o lê como parte do comando. Um nome, como uma tabela ou uma coluna, não pode ser passado assim: verifique-o com DBMS_ASSERT (SIMPLE_SQL_NAME, ENQUOTE_NAME), que causa um erro para qualquer coisa que não seja um nome. DBMS_ASSERT.NOOP não verifica nada.

Esta regra reporta um parâmetro de caracteres escrito diretamente no texto: na expressão do comando, numa variável local atribuída uma vez e depois executada, ou como o comando inteiro. Um parâmetro dentro de outra função ou expressão não é reportado.

Exemplo de código não conforme

create procedure find_crate(p_code varchar2, p_table varchar2) is
  n number;
begin
  execute immediate 'select count(*) from crate where code = ''' || p_code || '''' into n; -- Não conforme
  execute immediate 'select count(*) from ' || p_table into n; -- Não conforme
end;

Solução conforme

create procedure find_crate(p_code varchar2, p_table varchar2) is
  n number;
begin
  execute immediate 'select count(*) from crate where code = :c' into n using p_code;
  execute immediate 'select count(*) from ' || dbms_assert.simple_sql_name(p_table) into n;
end;
