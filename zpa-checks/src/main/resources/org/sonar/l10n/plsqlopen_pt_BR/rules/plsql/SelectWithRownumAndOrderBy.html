Numa consulta, a cláusula WHERE é aplicada antes do ORDER BY. Uma condição sobre ROWNUM na mesma consulta mantém, portanto, as primeiras linhas que o Oracle por acaso lê, e só essas são ordenadas: WHERE ROWNUM <= 5 ORDER BY created_at DESC não retorna as cinco linhas mais novas.

Esta regra reporta uma comparação com ROWNUM na cláusula WHERE de uma consulta que tem ORDER BY. Ordene numa subconsulta e filtre por ROWNUM fora dela, ou use FETCH FIRST n ROWS ONLY.

Exemplo de código não conforme

select c.code, c.created_at
  from crate c
 where rownum <= 5 -- Noncompliant
 order by c.created_at desc;

Solução conforme

select c.code, c.created_at
  from crate c
 order by c.created_at desc
 fetch first 5 rows only;
