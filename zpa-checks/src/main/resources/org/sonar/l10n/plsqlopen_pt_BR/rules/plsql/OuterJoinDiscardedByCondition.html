Nas linhas que um outer join adiciona para uma origem sem linha correspondente, todas as colunas dessa origem são nulas. Uma condição que nunca é verdadeira para uma coluna nula dessa origem, escrita no WHERE ou no ON de um inner join posterior, remove exatamente essas linhas: o outer join passa a dar as mesmas linhas que um inner join. O código executa, mas as linhas sem correspondência desaparecem.

Comparações, LIKE, BETWEEN, IN com uma lista e IS NOT NULL sobre uma coluna da origem do outer join são reportados quando se aplicam à consulta inteira: sozinhos ou ligados ao resto da condição por AND. Uma condição que mantém as linhas nulas, como IS NULL, NVL ou um OR com IS NULL, não é reportada. Na sintaxe antiga de join, uma condição cuja coluna é marcada com (+) pertence ao outer join e também não é reportada.

Exemplo de código não conforme

select count(*)
  into n
  from shelf s
  left join crate c on c.shelf_id = s.id
 where c.color = 'RED'; -- Não conforme

Solução conforme

select count(*)
  into n
  from shelf s
  left join crate c on c.shelf_id = s.id and c.color = 'RED';
