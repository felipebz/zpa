Espera-se que uma função calcule um valor a partir dos seus argumentos e o retorne. Um parâmetro OUT ou IN OUT lhe dá um segundo resultado, escondido: nada em l_total := order_total(p_order, l_count) diz que l_count muda. Uma função assim também não pode ser chamada em SQL (ORA-06572).

Esta regra reporta um parâmetro OUT ou IN OUT de uma função. Retorne os valores juntos, como um record ou um objeto, ou transforme a função numa procedure com apenas parâmetros OUT.

Exemplo de código não conforme

create function order_total(p_order number, p_lines out number) return number is -- Noncompliant
  l_total number;
begin
  select sum(amount), count(*) into l_total, p_lines from order_line where order_id = p_order;
  return l_total;
end;

Solução conforme

create procedure order_totals(p_order number, p_total out number, p_lines out number) is
begin
  select sum(amount), count(*) into p_total, p_lines from order_line where order_id = p_order;
end;
