Dentro de um comando SQL, uma coluna de uma origem em escopo toma um nome não qualificado antes de um parâmetro, variável ou constante de mesmo nome. Quando uma condição ou o valor de um SET se refere ao nome PL/SQL, o Oracle lê a coluna no lugar dele: a condição compara a coluna com ela mesma, e o SET grava a coluna de volta sem alterá-la. O código compila e executa, mas afeta as linhas erradas.

Esta regra reporta esse nome somente quando a existência da coluna é comprovada: pelos metadados de tabelas e views lidos do banco de dados, ou por uma tabela que os fontes analisados criam. Um nome na lista do select, no ORDER BY, no GROUP BY, num destino de INTO ou no VALUES de um INSERT de uma linha não é reportado.

Exemplo de código não conforme

create procedure drop_crates(shelf_id number) is
begin
  delete from crate where crate.shelf_id = shelf_id; -- Não conforme
end;

Solução conforme

create procedure drop_crates(shelf_id number) is
begin
  delete from crate where crate.shelf_id = drop_crates.shelf_id;
end;
