Para anotações únicas repetidas, o utPLSQL mantém a primeira anotação e emite um aviso para as ocorrências posteriores. Um %test de procedimento é incompatível com %beforeall, %afterall, %beforeeach e %aftereach; o utPLSQL emite um aviso para a anotação de configuração ou limpeza. O PL/SQL pode ser compilado normalmente, mas a anotação conflitante não tem efeito no utPLSQL.

Código em desconformidade

CREATE PACKAGE test_pkg AS
  -- %test
  -- %test(Descrição de teste duplicada)
  PROCEDURE some_test;
END test_pkg;

Código correto

CREATE PACKAGE test_pkg AS
  -- %test(Descrição de teste)
  PROCEDURE some_test;
END test_pkg;

Vários procedimentos distintos com %beforeall, %afterall, %beforeeach, %aftereach, %beforetest e %aftertest são válidos e não são reportados por esta regra.
