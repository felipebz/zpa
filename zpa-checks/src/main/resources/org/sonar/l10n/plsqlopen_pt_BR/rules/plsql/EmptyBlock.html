Um bloco, subprograma ou tratador de exceção cujo único comando é NULL não faz nada. Na maioria das vezes, o código que deveria estar ali está faltando: uma procedure deixada como esboço, ou um tratador escrito para calar um erro. Quando não fazer nada é intencional, o código não diz por quê.

Esta regra reporta um comando NULL que é o único comando de um bloco, subprograma, trigger ou corpo de método. Um membro OVERRIDING de um tipo objeto não é reportado: ali, um corpo vazio pode substituir de propósito o comportamento do supertipo.

Exemplo de código não conforme

create procedure refresh_rack(p_rack number) is
begin
  null; -- Noncompliant
end;

Solução conforme

create procedure refresh_rack(p_rack number) is
begin
  update rack set refreshed_at = sysdate where id = p_rack;
end;
