x NOT IN (a, b, c) significa x <> a AND x <> b AND x <> c. Quando um dos valores é nulo, a sua comparação é desconhecida para qualquer x, então a condição inteira nunca é verdadeira: um WHERE com ela não retorna linhas, e um IF nunca executa o seu ramo. O Oracle também trata '' como nulo. x <> ALL (subconsulta) é a mesma condição.

Esta regra reporta um NOT IN cuja lista contém o literal NULL ou '', que nunca é verdadeiro. Ela também reporta um NOT IN ou <> ALL sobre uma subconsulta cuja única coluna pode ser nula: os metadados do banco dizem que a coluna aceita nulo, ou um outer join da subconsulta gera nulos para ela, e nenhuma condição do WHERE da subconsulta rejeita nulo para essa coluna. A consulta funciona até um nulo ser selecionado, e então passa a não retornar linhas, sem erro. Sem os metadados, só as listas são verificadas.

Exemplo de código não conforme

-- bin_item.rack_id pode ser nulo
select count(*)
  into idle_racks
  from rack
 where id not in (select rack_id from bin_item);

Solução conforme

select count(*)
  into idle_racks
  from rack r
 where not exists (select 1 from bin_item b where b.rack_id = r.id);

select count(*)
  into idle_racks
  from rack
 where id not in (select rack_id from bin_item where rack_id is not null);
