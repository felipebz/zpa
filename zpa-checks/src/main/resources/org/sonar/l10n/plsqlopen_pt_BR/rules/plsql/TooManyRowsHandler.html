Quando um comando SELECT INTO causa a exceção pré-definida TOO_MANY_ROWS os valores das variáveis na cláusula INTO ficam indefinidos.

Exemplo de código não conforme

begin
  select empno
    into var
    from emp;
exception
  when too_many_rows then
    null;
end;

Solução conforme

begin
  select empno
    into var
    from emp;
exception
  when too_many_rows then
    var := null;
end;
