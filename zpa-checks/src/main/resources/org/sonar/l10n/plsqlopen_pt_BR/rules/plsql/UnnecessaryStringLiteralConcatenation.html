Dois literais de string unidos por || na mesma linha são uma constante dividida sem motivo: o leitor precisa juntá-los para ver o texto, e a falta de um espaço na junção passa despercebida com facilidade.

Esta regra reporta literais de string não vazios adjacentes unidos por || na mesma linha. Uma concatenação dividida em linhas para manter um texto longo legível não é reportada, nem uma com um comentário entre os literais, uma que mistura literais nacionais (N'...') e do banco, ou uma cujo literal unido poderia passar do limite do Oracle para um literal.

Exemplo de código não conforme

l_text := 'Rack is ' || 'full'; -- Noncompliant

Solução conforme

l_text := 'Rack is full';
