Um parâmetro escrito sem modo é IN. Escrever o modo de todo parâmetro torna visível no cabeçalho a direção de cada um, e faz um parâmetro IN parecer intencional, e não esquecido, ao lado de parâmetros OUT.

Esta regra reporta um parâmetro declarado sem IN, OUT ou IN OUT.

Exemplo de código não conforme

create procedure move_crate(p_crate number, p_rack out number) is -- Noncompliant
begin
  select rack_id into p_rack from crate where id = p_crate;
end;

Solução conforme

create procedure move_crate(p_crate in number, p_rack out number) is
begin
  select rack_id into p_rack from crate where id = p_crate;
end;
