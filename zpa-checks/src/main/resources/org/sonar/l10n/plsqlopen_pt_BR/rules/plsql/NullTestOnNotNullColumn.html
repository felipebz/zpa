Uma coluna com uma restrição NOT NULL habilitada, ou que faz parte de uma chave primária, nunca contém null. Uma condição IS NULL sobre ela é sempre falsa, então um WHERE que a exige não seleciona nenhuma linha, e uma condição IS NOT NULL sobre ela é sempre verdadeira e não filtra nada. Ou a condição é inútil, ou ela testa uma coluna diferente da pretendida.

Esta regra usa os metadados de tabelas e views lidos do banco de dados, e não reporta nada sem eles. Uma coluna só é reportada quando o banco garante que nenhuma linha contém null: uma restrição NOT NULL desabilitada, NOVALIDATE ou adiável não conta, e uma restrição CHECK também não. Uma coluna lida do lado de um outer join que não tem linha correspondente é nula mesmo quando a tabela não permite, então ela nunca é reportada.

Código em desconformidade

-- shipments.tracking_code é declarada NOT NULL
select count(*)
  into pending
  from shipments
 where tracking_code is null;

Código correto

select count(*)
  into pending
  from shipments
 where delivered_on is null;
