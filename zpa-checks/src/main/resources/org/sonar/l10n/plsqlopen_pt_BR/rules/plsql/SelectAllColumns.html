SELECT * retorna as colunas que as tabelas tiverem quando o comando for executado. Código que lê o resultado em variáveis ou por posição quebra, ou lê a coluna errada, quando uma coluna é acrescentada, removida ou reordenada. Ele também busca colunas que ninguém usa, e esconde do leitor de quais dados o código depende.

Esta regra reporta * e tabela.* numa lista de SELECT. Não é reportado onde a linha inteira é o objetivo: numa subconsulta de EXISTS, num SELECT ... INTO cujo destino pode ser um record da linha, e num cursor lido com fetch para um record assim.

Exemplo de código não conforme

declare
  cursor c_racks is
    select * -- Noncompliant
      from rack;
begin
  for r in c_racks loop
    refresh_rack(r.id);
  end loop;
end;

Solução conforme

declare
  cursor c_racks is
    select id
      from rack;
begin
  for r in c_racks loop
    refresh_rack(r.id);
  end loop;
end;
