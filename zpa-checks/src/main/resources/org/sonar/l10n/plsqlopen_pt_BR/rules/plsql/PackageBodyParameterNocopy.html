Faça com que a qualificação NOCOPY do parâmetro do corpo do pacote corresponda à do parâmetro da especificação.

Código em desconformidade

CREATE PACKAGE p AS
  PROCEDURE work(value IN OUT NOCOPY CLOB);
END p;

CREATE PACKAGE BODY p AS
  PROCEDURE work(value IN OUT CLOB) IS
  BEGIN
    NULL;
  END work;
END p;

Código correto

CREATE PACKAGE BODY p AS
  PROCEDURE work(value IN OUT NOCOPY CLOB) IS
  BEGIN
    NULL;
  END work;
END p;
