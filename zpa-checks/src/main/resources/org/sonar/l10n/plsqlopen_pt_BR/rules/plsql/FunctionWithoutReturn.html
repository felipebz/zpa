Uma função que chega ao seu END sem executar um comando RETURN lança o ORA-06503 ("PL/SQL: Function returned without value") quando é chamada. O Oracle alerta sobre algumas dessas funções na compilação (PLW-05005), só quando o PLSQL_WARNINGS o habilita, e não alerta sobre um tratador de exceção que segue adiante. Esse tratador é a causa mais comum: ele registra o erro e chega ao fim da função.

Esta regra reporta uma função quando a execução pode chegar ao seu END, ou ao fim de um dos seus próprios tratadores de exceção, sem um RETURN. Um RAISE, uma chamada a raise_application_error ou uma chamada a uma procedure do mesmo arquivo que sempre lança um erro encerram o caminho. Um comando CASE sem ELSE não segue adiante quando nenhum ramo é escolhido: o Oracle lança CASE_NOT_FOUND. Um laço sem EXIT também não segue adiante. Funções PIPELINED, funções com GOTO e funções com compilação condicional não são verificadas.

Exemplo de código não conforme

create or replace function stock_level(p_item number) return number is
  l_level number;
begin
  select qty into l_level from warehouse_stock where item_id = p_item;
  return l_level;
exception
  when no_data_found then
    audit_pkg.note('no stock row for ' || p_item);
end;

Solução conforme

create or replace function stock_level(p_item number) return number is
  l_level number;
begin
  select qty into l_level from warehouse_stock where item_id = p_item;
  return l_level;
exception
  when no_data_found then
    audit_pkg.note('no stock row for ' || p_item);
    return 0;
end;
