Uma comparação com a mesma expressão nos dois lados quase sempre é um erro: em geral, um copiar e colar em que um lado deveria nomear outra coluna, variável ou alias. Quando não é, é um teste de nulo disfarçado: x = x é verdadeiro para qualquer valor e desconhecido para nulo, o que x IS NOT NULL diz claramente.

Esta regra reporta uma comparação (=, <>, <, >, <=, >=...) cujos dois lados são a mesma expressão, ignorando parênteses.

Exemplo de código não conforme

select c.code
  from crate c, rack r
 where c.rack_id = c.rack_id; -- Noncompliant

Solução conforme

select c.code
  from crate c, rack r
 where c.rack_id = r.id;
