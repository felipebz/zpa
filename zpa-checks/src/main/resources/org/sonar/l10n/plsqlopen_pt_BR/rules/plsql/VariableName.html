Uma convenção de nomes permite ao leitor distinguir à primeira vista uma variável de uma coluna, um parâmetro ou uma constante. Nomes que a seguem são mais fáceis de buscar e mais difíceis de confundir.

Esta regra reporta uma variável cujo nome não corresponde à expressão regular do parâmetro regexp. Por padrão ela é [a-zA-Z]([a-zA-Z0-9_]*[a-zA-Z0-9])?: um nome que começa com letra e não termina com sublinhado.

Exemplo de código não conforme

declare
  rack_label_ rack.label%type; -- Noncompliant
begin
  select label into rack_label_ from rack where id = 42;
end;

Solução conforme

declare
  rack_label rack.label%type;
begin
  select label into rack_label from rack where id = 42;
end;
