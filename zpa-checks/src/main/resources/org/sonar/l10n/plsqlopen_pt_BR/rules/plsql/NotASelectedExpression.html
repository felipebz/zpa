Num SELECT DISTINCT, toda expressão do ORDER BY precisa ser uma das expressões selecionadas, ou o alias de uma: as linhas são tornadas distintas antes de serem ordenadas, então um valor que não é selecionado não tem um único valor por linha. O Oracle rejeita uma consulta assim com o ORA-01791 ("not a SELECTed expression"). Versões antigas aceitavam algumas dessas consultas, que passam a falhar depois de uma atualização.

Esta regra reporta uma expressão do ORDER BY de um SELECT DISTINCT que não é uma expressão selecionada nem o seu alias. Uma posição (ORDER BY 1) não é reportada.

Exemplo de código não conforme

select distinct r.label
  from rack r
 order by r.capacity; -- Noncompliant

Solução conforme

select distinct r.label, r.capacity
  from rack r
 order by r.capacity;
