O TO_CHAR transforma um número ou uma data em texto, e texto é ordenado caractere a caractere: '15' vem antes de '5', e '02-10-2018' antes de '10-10-2017'. Um ORDER BY por TO_CHAR de um número ou uma data ordena, portanto, as linhas numa ordem que não corresponde nem aos números nem às datas, o que raramente é a intenção do código.

Esta regra reporta uma chamada a TO_CHAR como expressão do ORDER BY, e uma posição do ORDER BY (ORDER BY 2) que se refere a uma chamada a TO_CHAR selecionada. Ordene pelo próprio valor, e formate-o só na lista do SELECT.

Exemplo de código não conforme

select c.code, to_char(c.created_at, 'DD-MM-YYYY') as created
  from crate c
 order by to_char(c.created_at, 'DD-MM-YYYY'); -- Noncompliant

Solução conforme

select c.code, to_char(c.created_at, 'DD-MM-YYYY') as created
  from crate c
 order by c.created_at;
