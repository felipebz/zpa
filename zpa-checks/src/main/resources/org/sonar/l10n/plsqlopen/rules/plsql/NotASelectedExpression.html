In a SELECT DISTINCT, every expression of the ORDER BY must be one of the selected expressions, or the alias of one: the rows are made distinct before they are sorted, so a value that is not selected has no single value per row. Oracle rejects such a query with ORA-01791 ("not a SELECTed expression"). Older releases accepted some of these queries, which then fail after an upgrade.

This rule reports an ORDER BY expression of a SELECT DISTINCT that is neither a selected expression nor its alias. A position (ORDER BY 1) is not reported.

Noncompliant Code Example

select distinct r.label
  from rack r
 order by r.capacity; -- Noncompliant

Compliant Solution

select distinct r.label, r.capacity
  from rack r
 order by r.capacity;
