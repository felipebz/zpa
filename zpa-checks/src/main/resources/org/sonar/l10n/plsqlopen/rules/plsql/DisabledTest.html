When a test fails due, for example, to infrastructure issues, you might want to disable it temporarily. Disabled tests are not executed by utPLSQL and should be re-enabled when the problem is resolved.

This rule raises an issue for each effective utPLSQL test procedure annotated with %disabled.

Noncompliant Code Example

-- %test(my test)
-- %disabled(temporarily broken)
procedure test;

Compliant Solution

-- %test(my test)
procedure test;

Package-level and context-level %disabled annotations, helper procedures, package bodies, and functions are outside this rule's scope.
