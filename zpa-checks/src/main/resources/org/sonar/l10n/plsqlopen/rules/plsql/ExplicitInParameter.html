A parameter written without a mode is IN. Writing the mode for every parameter makes the direction of each one visible in the heading, and makes an IN parameter look deliberate rather than forgotten next to OUT ones.

This rule reports a parameter declared without IN, OUT or IN OUT.

Noncompliant Code Example

create procedure move_crate(p_crate number, p_rack out number) is -- Noncompliant
begin
  select rack_id into p_rack from crate where id = p_crate;
end;

Compliant Solution

create procedure move_crate(p_crate in number, p_rack out number) is
begin
  select rack_id into p_rack from crate where id = p_crate;
end;
