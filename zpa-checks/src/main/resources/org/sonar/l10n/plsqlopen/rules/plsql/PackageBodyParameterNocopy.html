Make the NOCOPY qualification of a package body parameter match the corresponding package specification parameter.

Noncompliant Code Example

CREATE PACKAGE p AS
  PROCEDURE work(value IN OUT NOCOPY CLOB);
END p;

CREATE PACKAGE BODY p AS
  PROCEDURE work(value IN OUT CLOB) IS
  BEGIN
    NULL;
  END work;
END p;

Compliant Code Example

CREATE PACKAGE BODY p AS
  PROCEDURE work(value IN OUT NOCOPY CLOB) IS
  BEGIN
    NULL;
  END work;
END p;
