Do not use a sequence NEXTVAL in a conditional CASE result when the value appears to be consumed only by the selected branch.

Oracle sequences are special expressions in SQL. A conditional result can be correct while evaluating NEXTVAL still advances the sequence. Keep the sequence operation outside the conditional result when that side effect must be conditional.

select case when status = 'NEW' then order_seq.nextval else 0 end
  from orders;

This rule reports only sequence references that ZPA can positively identify from project declarations. References to sequences outside the analyzed project may remain undetected. It does not analyze generic DECODE calls because the current AST cannot prove that an unqualified call is Oracle's built-in function.
